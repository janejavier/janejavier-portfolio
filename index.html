Braille Learning Kit Specifications

System Architecture: Designed around an iPhone sized 3D printed PLA case with recessed dome sockets for 6 solenoid actuators and a speech activation push button.

D Flip Flop Logic States:

  • Q0 (00): System powered OFF, no pin movement.
  • Q1 (01): System powered ON, no active movement.
  • Q2 (11): Power ON with active solenoid button movement (Voice + Button active).
  • Q3 (10): Button press without voice command (Initiates device shutdown sequence).

SoleMate Technical Architecture

Sensory Hardware: Utilizes piezoelectric force sensor matrix placed at key kinetic footprint pressure zones, paired with an MPU6050 accelerometer/gyroscope for slope estimation.

Microcontroller: ESP32 core processes analog resistance changes to calculate step metrics, estimated caloric expenditure, and lateral gait slants.

MATLAB Pressure Heatmaps: Streams real time pressure distribution profiles to MATLAB scripts, enabling visualization for medical arch analysis (flat foot vs high arch support tracking).

Target Detection Node Specifications

Computer Vision Pipeline: Processes camera feed through HSV (Hue, Saturation, Value) color space correction to handle lighting variations better than standard RGB masking.

OpenCV Filtering: Interactive trackbars allow live tuning of min/max HSV thresholds to generate clean binary mask overlays isolating red, yellow, and green target obstacles.

ROS Execution: Runs as a published C++ ROS node sending target bounding vectors directly to mobile TurtleBot navigation path planners.

Image Box: Braille Kit Prototype

Voice-Controlled Braille Learning Kit

An assistive device engineered within an iPhone form factor to teach braille basics. Uses a Raspberry Pi engine for speech recognition logic processing, an Arduino system managing solenoids, and a custom D flip-flop state machine layout. Case modeled in Blender and 3D printed using PLA.

Image Box: SoleMate Sensor Placement

SoleMate Smart Biometric Insole

A smart medical shoe layer tracking foot structural movement patterns to identify flat feet or high arches. Integrates an ESP32 processing board, physical piezoelectric force sensors, an MPU6050 accelerometer, and models dynamic pressure heat maps over custom MATLAB templates.

Image Box: Target Mask Filter

Autonomous Robot Target Detection

Developed real-time target identification and category separation codes using the HSV color space matrix. Integrated TurtleBot webcam streams inside the ROS development environment to generate automated boundary constraints and obstacle charts.

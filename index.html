Voice Controlled Braille Learning Kit

A portable assistive education tool designed for visually impaired learners, sized comparably to an iPhone.

Key Architecture & Logic

  • State Machine States: Q0 (00, power off, no movement), Q1 (01, power on, no movement), Q2 (11, power on, button movement), Q3 (10, button movement while power off).
  • Uses dual D flip-flops to remember current state and combinatorial logic gates for next state transitions.
  • Raspberry Pi handles Google Voice API recognition libraries via external sound card and microphone.
  • Arduino Uno processes commands and controls 6 solenoid actuators fitted with IN4007 flyback diodes.

Production Cost Breakdown

  • Raspberry Pi: 130 AED
  • Arduino Uno: 60 AED
  • Solenoid Actuators (x6): 108 AED
  • Sound Card & Microphone: 60 AED
  • SD Card & Diodes: 24 AED
  • Total Estimated Kit Cost: 382 AED
